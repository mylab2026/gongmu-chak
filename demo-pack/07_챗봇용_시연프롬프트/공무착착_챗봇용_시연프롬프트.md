# 공무착착 챗봇용 시연 프롬프트

## 사용 방법

1. 공무착착 Tree Builder에서 사업유형을 고르고 필요한 폴더와 계약명을 설정합니다.
2. `구성 복사` 버튼을 누릅니다.
3. 원래 사용하던 공무착착 챗봇 대화창에 아래 프롬프트와 복사된 선택결과를 붙여넣습니다.

## 프롬프트

```text
[공무착착 Tree Builder 선택결과]
사업유형: {앱에서 복사한 사업유형}
기준 템플릿: {앱에서 복사한 기준 템플릿}
번호처리: 체크 해제 결과를 반영하여 Tree Builder에서 이미 순연 완료한 최종 번호임

선택된 최종 구조:
{앱에서 복사한 선택 구조 전체를 이곳에 그대로 붙여넣기}

[실행 요청]
위 구조를 그대로 사용하여 Windows에서 실행 가능한 실제 .bat 파일을 생성해 첨부해 주세요. 설명이나 구조 요약만 하고 끝내지 말고 실제 .bat 파일 제공을 기본으로 하세요. 파일 첨부가 불가능한 경우에만 BAT 코드블록을 출력하세요.

위 번호는 이미 순연 완료된 최종 번호이므로 다시 원래 번호로 복원하거나 재번호하지 마세요.
숫자로 시작하지 않는 메모성 텍스트는 폴더로 만들지 마세요.
실제 계약명이 입력된 가변 항목은 해당 명칭으로 사용하고 그 하위 표준구조를 유지하세요.
BAT 파일은 반드시 한국어 Windows CMD 호환을 위해 CP949(ANSI) 인코딩으로 저장하고, @echo off, chcp 949 > nul, cd /d "%~dp0" 순으로 시작하세요.
BAT 파일이 저장된 위치에 "공사문서트리" 최상위 폴더를 생성하고 그 아래에 선택된 전체 구조를 생성하세요.
Tree Builder가 전달한 폴더명과 번호는 한 글자도 임의로 변경·보정·복원하지 마세요.
모든 md 경로는 큰따옴표로 감싸세요.
BAT 파일 자체는 UTF-8 또는 UTF-8 BOM으로 저장하지 말고 반드시 CP949(ANSI)로 저장하세요.
마지막에는 실제 생성 위치를 echo로 표시하고 pause를 넣으세요.
```

## 기능 범위

이 프롬프트는 Tree Builder가 선택한 폴더 구조를 만드는 Windows 배치 파일을 챗봇에 요청합니다. 문서 내용을 읽어 분류하거나 실제 문서를 정리·이동하는 기능은 이 흐름에 포함되어 있지 않습니다. 사진 모아보기는 생성된 폴더에 실제 사진을 넣어 정리하는 별도 시연 항목입니다.

시연 자료에 든 사업명·문서·금액은 모두 가상 데이터입니다.
