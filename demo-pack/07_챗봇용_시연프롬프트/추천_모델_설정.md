# 공무착착 지원 챗봇 — 추천 모델과 응답 설정

기준일: 2026-11-21. 아래는 운영자 설정안이며, SNU AI Chat 관리 화면에 실제 적용한 결과가 아니다.

| 설정 | 권장값 |
| --- | --- |
| 기본 모델 | GPT-6.1 Sol (모델 ID: gpt-6.1-sol) |
| 기본 모델이 선택 목록에 없는 경우 | Claude Sonnet 5.5 (claude-sonnet-5-5)를 대안으로 검수 |
| 답변 언어 | 한국어 |
| 일반 답변 길이 | 3~6문장, 조작 안내 최대 3단계 |
| 추가 질문 | 필요한 질문 1개씩 |
| 문서 검색 | 제공된 매뉴얼·지원 지식자료를 우선 |
| 웹 검색 | 일반 프로그램 사용법에는 사용하지 않음. 최신 외부 기준 확인을 요청받은 경우에만 공식 자료 확인 |
| 추론 강도 | 설정을 제공하는 경우 기본/낮음부터 검수 |
| 출력 상한 | 설정을 제공하는 경우 약 800 tokens로 시작. 실제 분량은 시스템 지침으로 조절 |
| 온도 | 모델과 화면이 지원하는 경우 0.2부터 검수. 미지원이면 기본값 유지 |

선정 이유: 이 챗봇은 매뉴얼에 근거한 사용 안내와 정리 이력 해석을 한 모델로 처리해야 하므로 GPT-6.1 Sol을 기본 운영 후보로 선택했다. 모델 간 실측 우열·속도·가격을 검증한 결과는 아니다. 짧은 응답은 모델 이름만으로 보장되지 않으므로 시스템 지침과 실제 질문 검수로 맞춘다.

근거: 사용자가 제공한 「붙여넣은 텍스트(1).txt」의 2026-10-27 모델 목록에 gpt-6.1-sol과 claude-sonnet-5-5가 포함돼 있다. 이 문서도 조직·그룹 권한에 따라 실제 목록이 달라진다고 명시한다. 현재 사용자 계정의 관리자 모델 목록과 호출 가능 여부를 직접 확인한 것은 아니다.
