# 공무착착 시연용 가짜 문서 세트

모든 사업명·기관명·금액·기록은 시연용 가상 데이터입니다.

## 구성
- 01_연간단가형, 02_기획부터형, 03_설계부터형, 04_시공부터형: 유형별 가짜 문서
- 05_공통_문서정리: 문서관리대장·파일명 안내
- 06_사진모아보기: 사용자가 제공할 사진을 나중에 추가할 위치
- 07_챗봇용_시연프롬프트: 지원 챗봇 시스템 지침·모델 추천·등록 방법

## 현재 제품 기준 정정
프로그램에는 폴더 구조 편집과 생성 기능이 통합돼 있습니다. 최신 지원 자료는 기획부터·설계부터·공사부터·연간단가 4개 유형과 문서 정리·찾기·모아보기 기능을 설명합니다. main/index.html은 예전 별도 웹 트리빌더이며 최신 Windows 프로그램의 전체 구현이 아닙니다.
지원 챗봇 자료와 프로그램 지원 기능은 codex/chatbot-support-handoff 브랜치에 있습니다. 최종 배포 목표는 EXE와 같은 버전 매뉴얼이며, 이 ZIP에는 최종 EXE가 들어 있지 않습니다.

## 검증 범위
이 가짜 문서 ZIP과 CSV의 구조 검사는 수행했습니다. 이전 index.html 문법 검사는 예전 웹 트리빌더 대상이므로 최신 Windows 프로그램의 검증을 뜻하지 않습니다. 이 시연 문서 세트를 최신 프로그램에 넣은 실제 정리·모아보기 시험은 아직 완료되지 않았습니다. 챗봇 지침 또한 학내 실제 모델 응답 검수 전입니다.

## 사진 추가
사진은 생성하지 않았습니다. 사용자가 사진을 보내면 내용과 유형에 맞는 폴더에 넣고 문서관리대장과 연결합니다.
