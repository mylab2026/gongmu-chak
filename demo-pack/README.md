# 공무착착 시연용 가짜 문서 세트

모든 사업명, 기관명, 연락처, 금액, 날짜와 기록은 시연 전용으로 만든 가상 데이터입니다. 실제 기관이나 계약과 무관합니다.

## 구성
- 01_연간단가형: 연간단가 계약의 기준단가, 작업요청, 검수 내역 예시
- 02_기획부터형: 최초 사업계획, 사용자 요구, 예산 검토 예시
- 03_설계부터형: 설계용역 착수, 검토의견, 성과품 관리 예시
- 04_시공부터형: 기존 설계자료로 시작하는 시공, 작업일지, 공정 점검 예시
- 05_공통_문서정리: 파일명 규칙과 문서관리대장
- 06_사진모아보기: 사용자가 보내줄 사진을 나중에 넣을 위치

## 현재 앱에서 시연
현재 gongmu-chak 화면에는 기획·설계형, 설계용역형, 시공중심형 세 가지 템플릿이 있습니다. 연간단가형 템플릿은 화면에 없어서 해당 샘플 문서는 별도 폴더로 준비했습니다. 화면 유형 검증은 제공 중인 세 템플릿에 한해 진행하세요.

시연할 때는 각 유형을 선택하고 폴더를 체크/해제한 뒤, 계약명 입력과 챗봇 전달용 복사 흐름을 확인하면 됩니다. 이 세트의 문서는 프로그램에 업로드하는 기능을 가정하지 않습니다.

## 사진 추가
사진을 받으면 06_사진모아보기/에 넣으면 됩니다. 권장 파일명: 유형_현장_날짜_순번_짧은설명.jpg (예: 시공부터_푸른솔초_20261121_01_교실철거전.jpg). 파일명과 위치는 받은 사진의 실제 내용에 맞춰 정리합니다.
