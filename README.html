공무착착 Windows 개인 시험판 0.11.4 · 챗봇 지원

챗봇 도움 · chatbot-support.1

상단 또는 AI 연결 설정 안의 챗봇 도움을 누르고 문의 내용을 적습니다. 사업을 고르지 않아도 설치·AI 연결 상담자료를 만들 수 있습니다. 사업 파일 목록·계약 현황·최근 이력은 별도 체크했을 때만 포함합니다.

상담자료 미리보기 후 민감한 내용을 지우고 복사하거나 TXT로 내려받아 SNU AI Chat의 공무착착 챗봇에 직접 첨부하세요. 자동 전송·AI 호출·파일 이동은 하지 않습니다. API 키와 문서 본문은 입력하지 마세요. 과거 회차 상세는 기존 누적 정리 이력 ZIP을 이용합니다.

지원 챗봇 운영자는 chatbot/SETUP.md와 SYSTEM-PROMPT.md를 사용합니다. 챗봇 관리 화면 등록 및 설치본 배포 승인은 별도입니다.

0.11.1 · 직접 재현 검증 보정

  • 설계변경 차수 묶음 속 계약서 첨부 이름 보존, AI 재검토 뒤 표준 차수 대응 및 수동 목적지 유지.
  • 원 공사계약일 이전 사진과 같은 공사의 사용자 완료 경계를 적용. 준공 직후는 확인하고 30일 이후는 공사 후 추정으로 구분.
  • 공문 폴더만으로 실제 첨부 사진을 제외하지 않고, 파일명만으로 공문을 확정하지 않음.
  • 숫자 파일명의 본문 후보 수집, 정확한 공문 필드/부서/월말 날짜, 검색 명령어 제거.
  • AI 판정은 내용 해시와 사업·문서 위치·조건별로 재사용하고 검증 중 변경된 문서는 보류.

합성 자료로 검사한 시험판입니다. 실제 사용자 PC/업무 자료/학내 AI 실호출은 미검증입니다. Windows 자동 검사 결과와 검증 한계는 QA-0.11.1.md 및 GitHub Actions를 확인하세요.

0.11.0 · 수정 요청서 v3 반영

  • 표준 위치와 차수를 먼저 맞춥니다. 예: 3109-1 설계변경1차(…) → 6 설계변경/1 1차 설계변경(안의 파일·하위 폴더 그대로). 날짜만 있는 폴더는 차수로 추측하지 않습니다.
  • 옛 32 기술지도 용역은 등록된 같은 용역 가지로 대응합니다. 계약서 폴더 아래로 통째로 넣지 않고, 위치가 불분명하면 보류합니다.
  • 연간단가 작업지시 관리 용역: 1 회의 및 협의기록 / 2 작업지시서/1 작업지시서 1차 및 계약서…
  • 품의 폴더: 품의 첨부(0. 결재참조, 3. 견적서 등, 번호·하위 폴더 그대로)는 1 품의서, 단독 계약서는 2 계약서.
  • 표준 위치에 맞지 않는 독립 자료 묶음만 A·B·C를 붙입니다. 메일 같은 묶음은 빈 폴더까지 폴더째 옮기고, 연결도에 “폴더 묶음 이동”으로 표시합니다.
  • “사진·자료 모아보기 → 정리 결과 점검”: 이전 이동 기록으로 원래 위치/현재 위치/바로잡을 위치를 보여주고, 승인한 파일만 옮깁니다. 비게 된 앱 생성 폴더만 지우며 되돌리기가 됩니다.
  • 사진: 이름·폴더 근거가 없으면 촬영일(EXIF)을 계약서 공사기간과 비교해 전·중·후를 정합니다. 공문 스캔 이미지는 사진에서 뺍니다.
  • “내 모아보기”: “2026년 3월 시공사 공문”처럼 적으면 조건(종류·발신·수신·기간·단어)으로 바꿔 보여주고 고칠 수 있습니다. PC에서 후보를 먼저 찾고, AI 확인은 버튼을 누를 때만 하며 결과를 저장해 다시 부르지 않습니다. 공문은 첫 장 이미지 카드로 봅니다.
  • 정리 완료 애니메이션: 문서 이름이 바뀌고 시공 폴더로 들어가는 장면(약 4.5초, 무음, 1회).

0.10.0

자료 묶음 a·b·c · 사진·공문 모아보기 · 준공·인수인계 내보내기

  • 분류 폴더 번호(예: 5 회의 및 협의기록)는 그대로 두고, 분류 폴더로 옮겨지는 자료 묶음 폴더 앞에 a, b, c를 붙입니다. 원래 날짜와 제목은 유지하고 날짜를 새로 만들지 않습니다. 확인된 옛 위계 번호(예: 3107-2)만 지웁니다.
  • 기존 회의·협의기록은 하위 폴더·빈 폴더·바로가기만 있는 폴더까지 통째로 옮깁니다.
  • 첨부(공문·사진·도면)는 갑지와 같은 묶음에 둡니다. 평소 정리에서는 바로가기(.lnk)나 사본을 만들지 않습니다.
  • 시작 화면의 “사진·공문 모아보기”: 사진은 공사 전/중/후/확인 필요로, 공문은 따로 모아 봅니다. 파일은 옮기지 않고 AI도 쓰지 않습니다.
  • 같은 화면의 “준공·인수인계 내보내기”: 승인할 때만 사진·공문 바로가기, 사업 안내문, 자료 목록(CSV)을 만듭니다. 사용자 파일은 덮어쓰지 않습니다.
  • 정리 완료 창에 파일명 안내와 짧은 무음 애니메이션을 한 번 보여줍니다.

이전 0.9.3

0.9.3 · 계약서 배치·폴더 대응 수정

  • 기술지도 등 작업지시만 관리하는 용역: 1 계약서 / 2 회의 및 협의기록 / 3 작업지시서. 하위는 1 작업지시 1차, 2 작업지시 2차입니다.
  • 계약서는 파일 내용 해시와 확인된 계약 정보로 공사·설계·기술지도 계약을 구분합니다. 확인되지 않은 계약서를 다른 용역 폴더로 추측 배치하지 않습니다.
  • 체결일이 확인된 계약서는 YYMMDD와 계약 종류·건명으로 이름을 정리합니다. 최초·변경 계약은 각각의 체결일을 사용합니다. 이름 변경안은 파일 이동 확인에 표시되며 이동 승인 때 적용하고, 되돌리면 원래 이름도 복원합니다. 체결일이 불명확하면 임의 날짜를 넣지 않습니다.
  • 2101, 2107-1, 3113 같은 옛 표준 폴더는 대응하는 새 표준 폴더로 합치고, 날짜·사용자 하위 폴더는 보존합니다.
  • 기존 정리 오류를 다시 확인하려면 파일 이동 화면의 기존 정리 결과도 점검을 누르세요. 이동 전에는 정리안만 준비합니다.

0.9.2 · 자동 찾기와 자료 연결

  • 사업 폴더에서 계약서 후보를 자동으로 찾아 등록 화면에 채웁니다. PDF는 첫 페이지, HWP/HWPX/DOCX/TXT는 PC에서 추출한 본문 앞부분만 사용합니다. 사용자가 결과를 확인하고 다음을 누릅니다.
  • 이미 읽은 같은 내용은 PC 캐시에서 재사용합니다. 같은 계약의 변경본은 계약 체결일 기준 최신 정보로 반영하고, 계약번호나 체결일이 모호하면 개별 확인 대상으로 남깁니다.
  • 실제 파일은 표준 분류 위치에 보관합니다. 보고자료 및 첨부 관계는 해당 보관 폴더로 가는 이름 있는 .lnk 바로가기로 연결합니다. 바로가기 생성 오류는 화면에서 다시 시도할 수 있습니다.
  • 날짜별 협의자료는 폴더 묶음과 하위 구조를 유지합니다. 모호한 목적지는 붉은 선으로 표시되며 묶음 내 하나의 목적지를 바꾸면 함께 바뀝니다.

이전 화면 수정 포함

  • 설계·용역·도급공사·관급자재 이름을 글자에서 바로 수정하며 Ctrl+Z로 구조 편집을 되돌립니다.
  • 필수 항목의 !는 선택 즉시 사라지고, 용역 방식도 선택 즉시 반영합니다.
  • 계속 정리에서는 사업 선택 후 바로 진행하며, 저장된 폴더를 찾지 못할 때만 다시 연결하도록 안내합니다.
  • 정리 마치기는 파일 이동 실행 옆에 비활성화로 표시되며 이동 완료 후 활성화됩니다.
  • 처음 설치는 설치.cmd, 기존 설치 갱신은 실행 창을 닫고 업데이트.cmd를 실행하세요.

  • “확인할 파일만 모아보기”로 불확실한 파일만 목록으로 보고 바로 목적지를 고칠 수 있습니다.

0.8.0

  • 계약서를 입력칸에 끌어 놓아 등록할 수 있고, “추가 계약서 없음”을 누르지 않아도 다음으로 넘어갑니다.
  • 계약명을 보고 계약 폴더 이름(도급공사, 설계용역, 재해예방 기술지도 용역, 감리용역 등)을 자동으로 짓습니다. 부수 용역은 “해당 없음”을 고를 수 있습니다.
  • 사업유형 이름을 기획부터/설계부터/공사부터/연간단가 유형으로 바꾸고, 필수 선택 항목에 ! 표시를 합니다. “인수인계” 폴더 이름을 단순화했습니다.
  • 보고서 폴더(보고·검토·회의·계획 등, 1. 2. 번호나 붙임 파일)는 원본은 표준 분류 위치에 보관하고, 보고자료에서 보관 폴더로 가는 바로가기로 연결합니다. 같은 이름·크기의 파일은 내용까지 비교해 중복 바로가기를 만들지 않습니다.
  • 확인이 필요한 파일은 목록 대신 한 줄 안내와 붉은색 화살표로 표시합니다. 선택 파일 목적지 변경·AI 발췌 검토 버튼은 없앴습니다.

0.7.0 · 첨부 문서와 확인 목록

  • 실행 시점: 3단계 “다음”에서는 아무 폴더도 만들지 않습니다. 4단계에서 파일 이동 실행 → 확인을 누르는 순간 새 폴더 구조가 만들어지고 파일이 이동합니다.
  • 되돌리기: 이동 직후 “방금 이동 되돌리기” 버튼으로 파일을 원래 위치로 돌리고, 이번에 새로 만든 빈 폴더와 바로가기도 지웁니다.
  • 첨부 문서: 보고자료·검토의견서 같은 갑지와 같은 폴더에 있는 첨부 파일(붙임·첨부, 날짜 행사 폴더의 다른 문서)을 찾아 제안합니다. 첨부 관계를 연결해도 원본은 표준 분류 위치에 두고, 보고자료 쪽에 보관 폴더로 가는 바로가기를 만듭니다.
  • 다시 확인해 주시겠어요?: 목적지를 못 정한 파일, AI가 확신하지 못한 파일, 같은 폴더 파일들과 다른 곳으로 가는 파일만 따로 보여줍니다. 나머지 안내는 할 일이 있을 때만 표시합니다.

0.6.0 · 폴더 번호와 구조 그림

  • 짧은 번호: 층마다 1부터 번호를 붙입니다(예: 1 공통 / 1 사업계획서). 쓰지 않는 폴더를 제외하거나 추가·이동하면 번호가 자동으로 다시 매겨집니다.
  • 표준 폴더 이름 고정: 통일성을 위해 표준 폴더 이름은 바꿀 수 없고, 직접 추가한 폴더만 이름을 바꿀 수 있습니다.
  • 사업 등록 후: 이미 만든 폴더 번호는 유지하고, 새로 추가한 폴더는 같은 층의 다음 번호로 붙습니다. 정리 기록은 폴더 이름으로 기억하므로 번호가 달라도 같은 폴더를 찾습니다.
  • 0 정리할 문서 모음: 새 문서를 넣는 폴더 이름이 바뀌었습니다. 이전 버전에서 등록한 사업은 00 정리할_원본문서를 그대로 사용합니다.
  • 폴더 구조 한눈에 보기: 폴더 구조 만들기와 문서 어디 있지?에서 최상위 폴더를 같은 크기의 동그라미로, 그 아래 폴더를 이름표로 보여줍니다. 문서 어디 있지?에서는 이름표를 누르면 그 폴더의 문서가 나옵니다.

0.5.1 · AI 연결 설정

  • 등록을 마쳤다면 현재 모델과 이번 달 API 호출 횟수를 먼저 보여줍니다. 화면 위쪽에도 항상 표시됩니다.
  • 모델은 그 자리에서 선택한 뒤 연결 확인·저장으로 바꿉니다. 상위 모델(Pro 등)을 고르면 토큰을 많이 쓴다는 경고와 확인 창이 나옵니다.
  • API 키는 “API 키 변경”을 눌렀을 때만 입력란이 열립니다.
  • 처음 등록할 때는 Gemini 3.1 Flash(gemini-3.1-flash-lite)가 기본으로 선택됩니다. 모델 목록을 불러오면 학내 게이트웨이의 정확한 Gemini 3.1 Flash ID를 자동으로 고릅니다.

0.5.0에서 바뀐 점

  • 보류 파일이 있어도 이동 가능: 목적지를 정한 파일만 옮기고, 보류 파일은 원래 위치에 그대로 둡니다.
  • 같은 이름 파일: 덮어쓰지 않고 확인 후 견적서 (2).pdf처럼 번호를 붙여 저장합니다.
  • AI는 꼭 필요할 때만: 이전 정리 기록, 파일명·기존 폴더 이름, 문서 첫머리를 PC에서 먼저 확인하고 남은 파일만 AI가 분류합니다. AI 연결 설정에서 자동 분류를 끌 수 있고 이번 달 호출 수를 볼 수 있습니다.
  • 문서 어디 있지?: 정리해 둔 사업에서 파일명·폴더·문서 내용으로 찾고, 파일 열기 또는 폴더에서 보기를 누릅니다. “AI로 더 정확히 찾기”는 누를 때만 AI를 사용합니다.
  • 더 빠르고 멈추지 않음: 정리안을 만들 때 파일 전체를 읽지 않으며, AI 응답을 기다리는 동안에도 화면이 멈추지 않습니다.
  • 인터넷 없이 설치: Offline 패키지는 압축을 풀고 설치.cmd만 실행하면 됩니다.

자동 진행과 여러 파일 목적지 변경

  • 3단계: 사업유형과 연간단가 공사/용역·계약 관리 방식을 선택하면 구조가 자동 표시됩니다. 상위 폴더를 음영으로 구분하며 기본은 3계층까지만 표시하고 4계층부터 접습니다.
  • 4단계: 다음을 눌러 들어오면 파일명·기존 경로 기반 AI 일괄 분류가 자동 실행됩니다. 저장된 유효 결과는 재사용합니다. 오류나 중단 뒤에는 AI 다시 분류로 이어갈 수 있습니다.
  • 구조 수정: 이미 사업을 등록한 뒤 폴더 구조를 바꾸어 적용하면 기존 제안·수동 경로 초기화와 AI 재분류 경고를 표시합니다. 실제 파일·이동 이력·계약 정보는 삭제하지 않습니다.
  • 사진 30개 함께 변경: 왼쪽 체크박스 또는 이 폴더 파일 모두 선택을 사용한 뒤 선택 파일 목적지 변경을 누르거나 선택한 파일 중 하나를 원하는 폴더 행으로 끌어 놓습니다. 선택된 파일들의 목적지가 함께 저장됩니다. 실제 이동은 별도의 파일 이동 실행에서 진행합니다.
  • 드롭 위치: 폴더 행 전체를 넓힌 영역으로 사용합니다. 드래그 중 파란 테두리와 전체 목적지 경로를 확인하세요. 화살표 끝을 끌 때도 실제 폴더 행의 화면 범위로 판단합니다.

선택 파일 AI 발췌 검토는 이름만으로 판단하기 어려울 때 최소 본문만 추가로 읽는 선택 기능입니다. 이번에 읽은 문서 위치는 실제 읽은 경로와 범위를 확인하는 안내이므로 유지합니다.

계약서 등록 화면 변경

처음에는 1번·2번 계약서 입력이 표시됩니다. 각 칸의 ‘파일로 등록’ 또는 ‘캡처 이미지로 등록’ 중 한 가지를 사용하세요. 입력이 들어오면 실제 AI 자동 추출이 시작되며 별도 추출 버튼을 누르지 않습니다. 2번을 등록하면 3번, 3번을 등록하면 4번 입력칸이 생깁니다. 마지막 칸의 추가 계약서 없음으로 입력을 마칩니다.

PDF는 Windows 파일 선택창으로 고르며, 원본 전체를 브라우저에 업로드하지 않습니다. PC에서 첫 페이지만 이미지로 만들어 AI에게 보냅니다. 원본 용량이 20MB·100MB를 넘는다는 이유로 등록을 거절하지 않습니다. 원본은 선택한 경로에 두며, 사업의 관리자료에는 첫 페이지 사본과 추출 정보를 보관합니다. 첫 페이지에 필요한 정보가 없으면 해당 부분을 캡처해 다시 등록해주세요.

캡처 이미지로 등록을 누르고 열린 영역에 Ctrl+V로 붙여넣거나 저장된 이미지를 선택하세요. 붙여넣은 이미지는 최대 1800px로 줄여 전송합니다. 자동 추출이 실패하면 해당 계약서에 오류와 재시도 버튼이 표시됩니다. 추출된 건명·상대자·기간·계약 종류는 확인·수정할 수 있으며, 수정한 내용으로 저장합니다. 계약서가 전혀 없으면 ‘계약서 없음’을 선택합니다.

실제 파일을 이동하고, 이동 후 비어 있는 기존 폴더를 제거하는 버전입니다. 처음에는 반드시 복사한 사업 폴더에서 테스트해주세요. Windows 실환경의 설치·브라우저 드래그는 제작 환경에서 검증하지 못했습니다.

설치 또는 업데이트

  1. 압축을 풀기 전에 받은 ZIP을 오른쪽 클릭 → 속성 → 일반 탭 아래 차단 해제에 체크하고 확인을 누릅니다. Windows 11의 스마트 앱 컨트롤은 인터넷에서 받은 .cmd·.ps1 실행을 막습니다. 이미 풀었다면 풀린 폴더를 지우고 차단 해제한 ZIP을 다시 풉니다. 스마트 앱 컨트롤 자체를 끄지는 마세요.
  2. ZIP 압축을 모두 풉니다.
  3. 기존 사용자는 공무착착의 검은 실행 창을 닫고 업데이트.cmd를 실행합니다. 사업·계약·AI 설정은 유지하며 구성요소를 다시 다운로드하지 않습니다.
  4. 처음 설치라면 설치.cmd를 실행합니다. 일반 패키지는 Python.org와 PyPI에서 실행 구성요소를 다운로드하고, Offline 패키지는 포함된 파일로 인터넷 없이 설치합니다.
  5. 바탕화면 공무착착 시험판을 실행합니다. 검은 창을 닫으면 프로그램이 종료되므로 사용하는 동안 최소화해 두세요.

서명된 단일 EXE가 아닌 설치 스크립트 방식입니다. Windows 10/11 64비트와 인터넷 연결이 필요합니다. 회사 보안 정책으로 차단되면 전산 담당자에게 확인해주세요.

AI 연결

  1. 학내 AI CHAT의 API Gateway에서 본인 API 키를 발급받습니다.
  2. AI 연결 설정에 키를 입력하고 모델 목록에서 선택하거나 모델 ID를 직접 입력합니다. 특정 모델로 고정하지 않습니다.
  3. 연결 확인·저장을 누릅니다. 기본은 텍스트 요청이며 이미지 입력 확인은 선택사항입니다. 계약서 PDF·캡처 분석에는 이미지 입력을 지원하는 모델을 선택해주세요.

키는 Windows DPAPI로 암호화해 PC에 저장합니다. 이후 모델만 바꿀 때 키를 비워두면 기존 키를 사용합니다. 게이트웨이는 https://api.baze.co/v1/gateway이며 Chat Completions 호환 대화형 모델을 사용합니다. HTTP 401 인증 오류와 HTTP 404 모델/경로 오류를 구분합니다.

처음 문서 정리

  1. 정리할 폴더 선택: 실제 문서를 관리할 최종 위치의 전체 사업 폴더를 선택합니다.
  2. 계약서 등록: 사업 폴더에서 찾은 계약서를 자동 입력합니다. 누락된 계약서만 PDF 또는 캡처로 추가해주세요. 마지막 칸에서 추가 계약서 없음을 선택합니다. 계약서가 없으면 ‘계약서 없음’을 선택합니다. PDF 첫 페이지만 전송하며, 필요한 정보가 뒤에 있으면 해당 부분의 캡처로 다시 등록합니다.
  3. 폴더 구조 만들기: 사업 이름과 사업유형을 확인합니다. 기본 구조를 불러와 폴더 이름·구성을 조정합니다. 연간단가의 공사/용역 및 직접계약/작업지시만 조합을 지원하며 부수 용역의 관리 방식도 별도로 확인합니다. 다음을 누르면 설정과 정리안을 준비합니다. 실제 폴더 생성과 파일 이동은 4단계의 이동 실행 확인 후에 이루어집니다.
  4. 파일 이동: 아래 설명처럼 연결도에서 조정하고 전체 이동을 실행합니다.

계속 문서 정리

사업의 00 정리할_원본문서에 새 문서를 넣고 대상 사업을 선택합니다. 등록된 계약 현황을 보고 추가 계약이 있을 때만 체크합니다. 평소에는 대상 사업 선택 → 파일 이동의 2단계입니다. 저장된 사업 폴더가 없어지면 다시 연결 안내가 나타납니다. 현재 사업 폴더를 선택해주세요.

파일 이동 화면에는 실제 읽은 경로와 파일 수를 표시합니다. 문서를 새로 넣었다면 ‘파일 목록 다시 읽기’를 누르세요. 문서가 00 밖에 있으면 ‘사업 전체 폴더에서 문서 찾기’로 이동 없이 검토할 수 있습니다.

파일 목록으로 AI 일괄 분류

파일 목록으로 AI 일괄 분류는 파일명·기존 상대 경로·확장자·크기·계약 건명·새 목적지 목록을 전송합니다. 문서 본문은 보내지 않습니다. 최대 24개 또는 목록 문자 수 기준으로 나눠 모든 대상 파일을 처리하며 진행 건수를 표시합니다.

기본은 보류 문서만 검토하고, 기존 규칙·AI 제안까지 다시 보려면 재검토 옵션을 체크합니다. 같은 내용·원래 경로·폴더 구조에 맞는 결과는 재사용합니다. 알 수 없는 파일/폴더 ID, 중복 결과는 적용하지 않으며 누락·불확실한 파일은 보류합니다.

연결도에서 직접 경로 조정

  1. 왼쪽 폴더를 펼쳐 개별 파일을 선택합니다. 해당 파일의 화살표가 강조됩니다.
  2. 파일 자체나 화살표 끝 동그라미를 오른쪽 새 폴더로 끌어 놓습니다.
  3. 드래그가 어렵다면 선택 파일의 목적지 바꾸기를 누른 뒤 오른쪽 폴더를 클릭합니다.
  4. 변경은 정리안에만 저장합니다. 아직 실제 파일을 이동하지 않습니다. 일반 문서 이름은 유지하며 계약서의 이름 변경안은 이동 전에 확인할 수 있습니다.
  5. 필요하면 연결도 위의 선택 파일 AI 발췌 검토로 PDF 처음 1쪽·이미지 첫 장·텍스트 앞부분 최대 6,000자를 추가 검토합니다. HWP/HWPX는 PDF 또는 캡처로 바꿔 검토하거나 목적지를 직접 지정해주세요.

파일 이동 실행

  1. 목적지가 지정된 파일은 표준 폴더로 이동합니다. 목적지를 정하지 않은 보류 파일은 원래 폴더 이름째 ‘0 정리할 문서 모음’으로 옮깁니다(예: 옛자료/기타/메모.txt → 0 정리할 문서 모음/옛자료/기타/메모.txt). 사업 폴더 바로 아래에 있던 낱개 파일은 정리할 문서 모음 바로 아래로 갑니다. ‘계속 정리하기’에서는 보류 파일이 이미 정리할 문서 모음 안에 있으므로 그대로 둡니다. 같은 이름이 있으면 번호를 붙이고 덮어쓰지 않습니다.
  2. 파일 이동 실행 → 최종 팝업의 확인을 누르면 실제로 이동합니다. 취소하면 연결도에서 다시 경로를 볼 수 있습니다.
  3. 실행 전 전체 파일의 목적지·동일 이름 충돌·내용 변경을 검사합니다. 문제가 있으면 첫 파일을 이동하기 전에 멈춥니다. 실행 중 외부 잠금 등으로 실패하면 사유를 표시하고, 실패한 파일이 있는 폴더만 남긴 채 나머지 빈 기존 폴더는 정리합니다.
  4. 실행 후 팝업에 실제 이동·기존 위치 유지·보류·빈 폴더 제거 수를 표시합니다. 완료되면 ‘정리 마치기’로 시작 화면에 돌아갑니다.

기존 폴더 정리와 되돌리기

모든 파일 이동이 끝나면 완전히 빈 기존 폴더만 제거합니다. 사업 루트·00 폴더·새 표준 트리·관리자료 폴더는 보호합니다. 파일이나 하위 폴더가 남은 폴더는 삭제하지 않습니다. 재귀 삭제는 사용하지 않습니다.

이동 전후 상대 경로·파일 해시·제거한 폴더를 기록합니다. 이동 직후 ‘이번 정리 되돌리기’에서 원래 폴더 구조와 파일을 복원합니다. 이동 후 파일이 수정됐거나 원래 위치에 다른 파일이 생기면 덮어쓰지 않고 복원을 보류합니다.

시험판의 한계

실제 Windows 설치·드래그의 시각적 동작은 검증하지 못했습니다. 파일 처리·경로 검증·빈 폴더 정리·되돌리기는 로컬 자동 검사로 확인했습니다. AI 정확도와 학내 크레딧 단가는 보장하지 않으며 제안 경로는 사용자가 확인해야 합니다. 이전 HTML 시연의 저장 정보는 자동 이전하지 않습니다. 사업 이름은 표시 이름이며 최상위 사업 폴더 자체를 이름 변경하지 않습니다.
