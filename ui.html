챗봇의 도움이 필요할 때 누적 정리 이력을 ZIP으로 내려받아 주세요. 압축을 풀고 해당 날짜·회차의 정리 이력.txt를 챗봇에 첨부하면 됩니다. 정리할 때마다 이동·보류·되돌리기 기록이 쌓입니다.

이 시험판은 확정한 실제 파일을 이동합니다. 이동 전 확인 팝업을 표시하며 동일 이름의 파일은 덮어쓰지 않습니다.

실제 문서를 관리할 최종 위치의 전체 사업 폴더를 선택해주세요.

시연은 실제 폴더 없이 진행합니다. 프로그램 데이터 폴더 안에 가짜 예시 문서로 된 사업 폴더를 새로 만들어 쓰며, 실제 업무 문서는 건드리지 않습니다. AI를 연결하지 않았다면 다음 단계에서 ‘계약서 없음’을 선택해 진행하세요.

계약서는 사업 구성을 파악하는 자료입니다. 계약을 등록하면 사업 단계와 문서 분류 정확도가 높아집니다.

화면 캡처는 이 영역을 클릭하고 Ctrl+V로 붙여넣으세요.

PDF는 PC에서 첫 페이지만 추출하고, 캡처는 이미지 한 장을 학내 API로 보냅니다. 원본 전체 PDF는 전송하지 않습니다. 필요한 정보가 첫 페이지에 없으면 해당 부분 캡처로 다시 등록해주세요.

폴더 구조

기존 Tree Builder의 구조입니다. 폴더 이름·구성을 조정할 수 있습니다. 계약서 이름은 확인한 체결일과 계약 종류로 정리하며, 일반 문서 이름은 유지합니다.

연결도에서 파일의 목적지를 조정한 뒤 파일 이동 실행을 누르세요. 목적지를 지정한 파일만 이동하며, 보류 파일은 원래 위치에 그대로 둡니다.

파일명·기존 폴더 경로·새 폴더 목록만 전송합니다. 문서 본문은 보내지 않습니다. 기본은 보류 문서만 검토하며 완료된 AI 제안은 재사용합니다.
