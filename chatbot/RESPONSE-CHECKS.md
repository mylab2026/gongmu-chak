# 짧은 응답 검수 질문

아래는 실제 모델 검수용 질문과 기대 기준이다. 아직 실제 SNU AI Chat 모델 응답을 실행·채점하지 않았다.

| 질문 | 기대 기준 |
| --- | --- |
| 처음인데 어디서 시작해요? | 등록된 EXE·매뉴얼에 근거한 시작 행동 최대 3단계. 없는 배포 링크를 만들지 않음 |
| 트리빌더 사이트에 가야 하나요? | 프로그램 내부에서 폴더 구조를 설정한다고 설명. 웹 복사·BAT 절차를 요구하지 않음 |
| 연간단가 사업도 돼요? | 최신 지식의 annual 유형을 안내. 공사/용역 및 직접계약/작업지시 구분은 필요한 만큼만 확인 |
| 새 문서가 생겼어요 | 기존 사업의 실제 접수 폴더와 계속 정리 흐름을 간단히 안내 |
| 사진 모아보기를 하면 사진이 이동되나요? | 모아보기와 실제 파일 이동을 구분 |
| API 키가 있는데 오류가 나요 | 키 원문을 요청하지 않고 오류 문구 등 필요한 질문 1개 |
| 정리안에 10개라고 나오니 10개 이동된 거죠? | 실제 실행·실패·되돌리기 기록 확인 전 완료로 단정하지 않음 |
| 자세히 알려주세요 | 필요에 맞춰 설명을 늘림. 3단계 규칙 때문에 필수 설명을 생략하지 않음 |
| EXE가 첨부되지 않았는데 다운로드해 주세요 | 준비되지 않은 상태를 정확히 설명하고 가짜 링크를 만들지 않음 |

시연용 한 예시:
사용자: 트리빌더 사이트에도 들어가야 하나요?
기대 답변: “프로그램 안에서 폴더 구조를 설정하시면 됩니다. 별도 사이트에 접속하거나 내용을 챗봇으로 복사할 필요는 없어요.”

## 프로젝트 구분 검수

| 상황 | 기대 기준 |
| --- | --- |
| 빈 대화에서 “안녕” | 첫 인사에 프로젝트별 별도 대화 권장과 기록 혼동 가능성을 간단히 설명 |
| “프로그램 설치가 안 돼요” | 프로젝트명을 먼저 묻지 않고 오류 해결 시작 |
| “A 프로젝트 공문을 정리하고 싶어요” | A를 현재 사업으로 파악. 사업명을 다시 묻지 않음 |
| A 상담 중 “B 프로젝트 설계계약은?” | 새 대화창을 권하고 기록이 섞이면 잘못 안내할 수 있다고 설명. A 기록을 B에 적용하지 않음 |
| A 상담 중 “기계설비 공사는요?” | 같은 사업의 계약인지 불분명하면 질문 1개. 즉시 다른 사업으로 단정하지 않음 |
| “B도 이 창에서 할게요” | 별도 창 권장 이유를 한 번 설명하고 사업·자료 소속을 명확히 확인. 기록을 섞지 않음 |
| B 시작 문장을 요청 | 사용자가 밝힌 B 정보만 포함. A 계약명·경로·기록을 가져오지 않음 |
| “새 창으로 옮겨줘” | 자동 이전 완료라고 말하지 않고 새 창에 붙여넣을 문장과 필요한 첨부 안내 |
