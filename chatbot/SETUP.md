# SNU AI Chat 공무착착 지원 챗봇 설정

이 챗봇은 EXE 배포, 매뉴얼 기반 사용 안내, 오류 해결, 사용자가 첨부한 정리 이력 해석을 담당한다. 트리 구성과 파일 정리는 공무착착 프로그램 안에서 수행한다.

1. 챗봇 설명을 “공무착착 설치·사용법·오류 해결과 정리 이력 확인을 도와드립니다.”로 설정한다.
2. SYSTEM-PROMPT.txt의 본문을 시스템 지침에 붙여넣는다. 이 파일을 참고 첨부만 하는 것으로 대신하지 않는다.
3. 모델 선택에서 GPT-6.1 Sol을 기본으로 지정한다. MODEL-SETTINGS.md의 권장값과 계정의 실제 선택 목록을 확인한다.
4. 최종 EXE는 사용자에게 내려줄 배포 첨부로, 같은 버전 PDF/TXT 매뉴얼은 챗봇이 검색·읽을 지식자료로 등록한다. EXE 자체는 매뉴얼을 대체하지 않는다. 해당 화면이 EXE 배포 첨부를 허용하지 않으면 학교에서 접근 가능한 배포 위치에 올리고 실제 링크를 등록한다.
5. KNOWLEDGE.md, TROUBLESHOOTING.md, TREE-REFERENCE.md, RELEASE-CATALOG.json을 보조 지식으로 등록한다. 기존 자료는 0.11.2-test 기준이므로 최종 EXE 출시 시 화면·설치·지원 형식의 변경을 반영한다. 서로 다른 버전을 현재 사용법으로 섞지 않는다.
6. RELEASE-CATALOG.json에 실제 배포 버전, 첨부 파일명 또는 URL, 같은 버전 매뉴얼, 확인된 지원 연락 경로를 등록한다. 현재 releases가 비어 있으므로 배포가 완료된 것으로 안내하지 않는다.
7. 시작 질문은 “프로그램을 처음 사용해요”, “새 문서를 계속 정리하고 싶어요”, “사진을 모아보고 싶어요”, “오류가 발생했어요”, “이 정리 이력을 설명해 주세요”로 둔다.
8. ACCEPTANCE.md와 RESPONSE-CHECKS.md의 질문을 실제 선택 모델에 넣어 답변 길이, 매뉴얼 근거, 첨부파일 읽기, 다운로드 링크를 검수한 뒤 배포한다.

현재 상태: 지침과 설정안만 준비했다. EXE 제작·최종 매뉴얼 첨부·학교 챗봇 관리자 설정·실제 모델 응답 검수는 완료되지 않았다.

첫 인사에는 프로젝트마다 대화창을 따로 쓰는 것을 권장한다는 안내를 포함한다. 사업 상담에 필요한 경우에만 프로젝트명을 확인하고, A에서 B로 전환되면 새 대화창을 권한다. 같은 사업의 별도 계약·공종은 새 사업으로 단정하지 않는다. 챗봇이 대화창을 자동 생성하거나 자료를 이전하는 기능을 설정한 것은 아니다.
