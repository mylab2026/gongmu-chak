# SNU AI Chat 공무착착 챗봇 등록

이 패키지는 지원 챗봇의 설정/지식자료다. 학내 관리자 화면에 자동 등록하거나 공개하지 않았다. 프로그램 내부 문서 분류 API의 프롬프트를 교체하는 자료가 아니다.

1. 관리자/스튜디오에서 공무착착 지원 챗봇을 생성한다. 표시 설명: ‘프로그램 설치·사용법·문제 해결과 내 정리 이력 분석을 돕습니다.’ 실제 메뉴명은 학내 UI를 따른다.
2. SYSTEM-PROMPT.md의 내용을 시스템 지침에 붙여넣는다. 단순 참고 첨부로만 두지 않는다.
3. KNOWLEDGE.md, TROUBLESHOOTING.md, TREE-REFERENCE.md, RELEASE-CATALOG.json을 지식자료로 등록한다. 읽기 가능한 첨부 형식은 학내 관리 화면에서 확인한다. 지원하지 않으면 같은 내용을 TXT로 등록한다.
4. 승인된 설치본을 챗봇의 첨부 저장소 또는 교내 배포 위치에 올리고, RELEASE-CATALOG.json에 실제 버전·첨부명/URL·해시·승인 상태를 입력한다. 공개/로그인 접근은 운영자가 결정한다. 현재 releases=[]이므로 챗봇이 다운로드 링크를 임의 생성하지 않도록 했다.
5. 실제 챗봇 URL과 담당 지원 연락처를 확보하면 카탈로그에 등록한다. 원격 PC 제어·임의 명령 실행·파일 이동 도구는 연결하지 않는다. 프로그램이 내보낸 자료를 사용자가 첨부하는 방식으로 먼저 운영한다.
6. 시작 질문(퀵버튼 지원 시): ‘프로그램 설치하고 싶어요’, ‘지금 화면에서 다음에 뭘 하나요?’, ‘오류가 발생했어요’, ‘이 정리 이력을 분석해주세요’, ‘문서를 어디에 보관하나요?’, ‘원하는 문서를 모아보고 싶어요’.
7. ACCEPTANCE.md의 합성 질문으로 실제 배포 모델에서 검수한다. ZIP/TXT 첨부 지원, 지식 검색, 다운로드 링크 접근과 시스템 지침 적용을 확인한다. 프로그램 단위 테스트 통과가 챗봇 모델 응답 검증을 대신하지 않는다.
8. 프로그램 업데이트마다 버전별 사용 안내·오류 안내·폴더 기준을 갱신한다. 여러 버전을 서비스하면 각 자료에 적용 버전을 명시한다. 오래된 개정 내역과 미구현 계획을 현재 사용법으로 섞지 않는다.

## 운영자가 채워야 하는 것
- 승인 설치본 및 실제 다운로드 URL/첨부 파일명(현재 미등록)
- 실제 공무착착 챗봇 URL(현재 미등록)
- 문의 전달 담당자/연락 경로(현재 미등록)
- 공식 업무 절차 상담을 제공하려면 학교 공식 매뉴얼과 개정일

일반 사용자 개별 이력/계약은 공용 지식자료에 등록하지 않는다. 대화에서 해당 사용자 상담에만 사용한다. 서버 보관 정책은 학내 서비스 정책을 별도로 따른다.
