# 문제 해결 기준

항상 사용자 버전과 실제 오류를 우선한다. 확인되지 않은 원인은 후보로 표시한다.

| 증상 | 먼저 확인 | 안전한 다음 행동 |
|---|---|---|
| 설치.cmd·업데이트.cmd가 ‘스마트 앱 컨트롤이 … 차단했습니다’로 막힘 | Windows 11인지, 받은 ZIP을 그대로 풀었는지 | 풀린 폴더를 지우고, ZIP 오른쪽 클릭 → 속성 → ‘차단 해제’ 체크 후 다시 풀어 실행. 스마트 앱 컨트롤을 끄라고 안내하지 않음(다시 켜기 어려움) |
| 새 PC에서 실행 안 됨 | ZIP을 모두 풀었는지, 최초 설치인지, 실행 파일 이름/오류 | 승인된 설치본의 설치.cmd 안내. 설치가 안 된 PC에서 run.cmd만 실행했다고 설치 완료로 보지 않음 |
| 화면 연결 끊김 / Failed to fetch | 검은 실행 창 종료 여부, 바탕화면 바로가기로 연 화면인지 | 프로그램 재실행 후 생성된 화면 사용. 이 문구만으로 API 키 문제로 확정하지 않음 |
| 인증 오류 401 | 실제 오류와 Gateway 키 등록 여부 | 프로그램 AI 연결 설정에서 본인 키 확인·재등록. 채팅에 키를 요청하지 않음 |
| 모델/경로 오류 404 | 정확한 모델 ID와 학교 제공 목록, 연결 형식 | 목록 새로 불러오기/ID 확인. 모델을 특정 이름으로 강제하지 않음 |
| 429/잔액 부족 | 오류 코드·안내, 반복 실행 여부 | 반복 클릭을 멈추고 학교 사용량/잔액 안내 확인. 무조건 무료·자동 충전된다고 보장하지 않음 |
| 계약서 일부를 못 읽음 | 첫 페이지에 정보가 있는지, 이미지 지원 모델인지 | 필요한 면만 추가 캡처하고 추출값 확인. 전체 계약을 무조건 올리라고 요구하지 않음 |
| 파일 0개 | 처음/계속 정리, 대상 사업, 실제 접수 폴더 | 현재 ‘0 정리할 문서 모음’ 또는 구버전 ‘00 정리할_원본문서’ 확인. 파일 목록 다시 읽기. 필요 시 사업 전체에서 찾기를 검토 |
| 다음으로 못 감 | 화면의 미선택 표시/오류, 사업유형/용역 관리 방식 | 누락된 항목만 안내. 계약서가 없으면 계약서 없음 선택 가능 |
| 문서가 잘못 분류됨 | 아직 정리안인지 실제 이동했는지, 갑지/첨부/원래 상위 경로 | 이동 전은 목적지 수정. 이동 후는 이력 확인 후 정리 결과 점검/되돌리기 범위 안내 |
| 첨부·날짜 폴더가 풀림 | 당시 회차와 현재 상태, 묶음 상대 구조 | 독립 문서와 첨부 구분, 묶음째 수정할 근거 제시. 파일 종류별로 다시 흩뜨리지 않음 |
| 동일 이름 충돌 | 목적지의 기존 파일, 실행/보류 상태 | 두 파일 존재를 확인하고 사용자 판단. 덮어쓰기·일괄 삭제를 제안하지 않음 |
| 되돌리기 보류 | 파일 수정/원래 위치 충돌/현재 위치 유무 | 보류 사유별 확인. 수정된 파일을 강제로 덮어쓰지 않음 |
| 모아보기에 없음 | 검색 조건, 실제 파일 위치, 확인/추정 구분 | 조건을 좁히거나 바꾸고 프로그램의 재확인 사용. 누락을 파일 삭제로 단정하지 않음 |
| 경로 변경/다른 PC | 사업 폴더 실물과 저장된 경로, 설정/이력 이전 여부 | 재연결 안내. 채팅이나 GitHub가 업무 파일을 자동 동기화한다고 말하지 않음 |

해결 안 될 때 개발자 전달 초안: 프로그램/빌드, Windows 버전(사용자가 제공한 범위), 발생 화면, 재현 단계, 예상 결과, 실제 결과, 오류, 회차 ID/시각, 시도한 조치, 추가 확인 필요. 사용자 승인 없이 외부 전달하지 않는다.
