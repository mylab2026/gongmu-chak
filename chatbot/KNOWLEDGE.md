# 공무착착 지원 지식 — 0.11.2-test / chatbot-support.1

기준: claude/step4-sticky-overlap 커밋 676606823a5425f62e3a11b7fcfea9572a29b011과 이 지원 기능 변경. 과거 README의 버전별 항목을 한꺼번에 현재 기능으로 해석하지 않는다.

## 적용 범위
이 문서는 0.11.2-test 지원 기능의 확인 자료다. 최종 배포 목표는 Windows EXE와 같은 버전 매뉴얼이다. EXE 출시 후 설치 방식과 바뀐 화면은 해당 매뉴얼을 우선하고 이 문서를 함께 갱신한다. 아래 설치.cmd 안내를 최종 EXE 설치법으로 자동 적용하지 않는다. 폴더 구성 기능은 프로그램 내부에 통합되어 있으며 별도 웹 트리빌더와 BAT 생성이 정상 사용의 필수 절차가 아니다.

## 현재 동작
- 개인 PC의 Windows 프로그램. 웹브라우저는 127.0.0.1 로컬 서버 화면이다. 검은 실행 창을 종료하면 서버도 종료된다.
- 최초: 전체 사업 폴더 선택 → 계약서 등록 → 폴더 구조 만들기 → 파일 이동. 계획 변경은 실제 이동이 아니며 이동 실행 확인 뒤 실제 파일을 옮긴다.
- 계속: 대상 사업 선택 → 파일 이동. 새 계약을 추가할 때만 계약 등록 화면을 거친다.
- 새 문서 접수 폴더는 현재 `0 정리할 문서 모음`. 구버전 사업은 `00 정리할_원본문서`를 유지할 수 있다. 사용자 트리의 실제 이름을 확인한다.
- 계약 후보를 사업 폴더에서 찾고 필요하면 사용자가 추가한다. PDF는 첫 페이지 이미지, 지원 문서는 앞부분 추출, 캡처는 한 장을 분석한다. 자동 추출 결과는 사용자가 확인한다. 계약서가 없으면 ‘계약서 없음 · 계약서 없이 진행’을 선택한다.
- 기본 유형: 기획부터(planning), 설계부터(design), 공사부터(construction), 연간단가(annual). 연간단가는 공사/용역과 직접 계약/작업지시 관리 조합을 확인한다. 부수 용역도 각기 관리 방식을 확인한다. 세부 표준은 TREE-REFERENCE.md, 실제 목적지는 사용자의 현재 트리 우선.
- 폴더 구조는 이름·추가·삭제·순서 등을 편집한다. Ctrl+Z의 구조 편집 복원과 실행 파일 되돌리기는 별개다.
- AI 분류에 파일명과 원래 상대 경로 등 목록을 사용한다. 자료 묶음·갑지 첨부·차수·사용자가 정한 목적지는 보존한다. 확신이 없으면 확인 대상으로 남긴다.
- 왼쪽 파일/묶음과 오른쪽 목적지의 연결을 검토한다. 여러 파일은 Shift 범위 선택이나 체크 후 함께 목적지를 수정할 수 있다. ‘맞아요’는 경로 확인이며 실제 이동 실행과 구분한다.
- 일반 파일명은 유지한다. 확인된 계약서 체결일·종류·건명에 따른 이름 변경안은 승인 후 적용되는 예외다. 첨부 묶음 내부 이름은 보존한다.
- 파일 이동 실행 때 목적지가 없는 보류 파일은 원래 폴더 경로째 ‘0 정리할 문서 모음’으로 옮긴다(사업 폴더 바로 아래 낱개 파일은 모음 바로 아래, 계속 정리하기에서는 그대로). 그래서 정리를 마치면 정리 전 폴더는 남지 않는다. Thumbs.db·desktop.ini·~$ 임시 파일은 문서가 아니라 ‘정리할 문서 모음/정리 후 남은 파일’로 모인다.
- 이동 전에 충돌/변경을 확인하며 덮어쓰지 않는다. 끝난 뒤 제거하는 것은 조건에 맞는 빈 폴더다. 실제 파일이 변경됐거나 원래 위치가 차 있으면 되돌리기를 보류할 수 있다.
- 찾기·모아보기는 원본을 다른 위치로 옮기는 기능이 아니다. 사진 전·중·후, 공문, 문장 검색 등을 활용한다. 날짜·기간 등에서 추정한 결과와 사용자가 확인한 구분이 다르다.
- 준공·인수인계 내보내기에는 자료 안내/목록/바로가기 기능이 있다. 월별 예정 업무·하자기간·미결 사항을 망라하는 상세 인수인계서 자동 생성은 NEXT-UPDATE.md의 미구현 계획이다.

## 설치와 PC 교체
승인된 설치 ZIP을 모두 압축 해제한 뒤 최초는 설치.cmd, 기존 사용자는 실행 창을 닫고 업데이트.cmd. 앱 경로는 `%LOCALAPPDATA%\Programs\GongmuChakTest`, 설정/이력은 `%LOCALAPPDATA%\GongmuChakData`, 계약 원본 사본은 사업 안의 `.gongmu-chak\contracts`에 저장된다. 이 폴더를 일반 오류 해결 목적으로 지우지 않는다.
다른 PC에 설치한다고 사업 문서와 설정이 자동 동기화되지 않는다. 사업 자료와 필요한 설정/이력의 이전은 별도로 점검한다. Windows 계정 암호화 API 키가 다른 PC에서도 그대로 작동한다고 보장하지 않는다. 새 PC에서는 본인 API 키를 다시 등록하는 흐름을 안내한다. 이력 ZIP은 진단 자료이며 문서 원본이나 완전한 복구 백업이 아니다.

## AI 연결
사용자 본인의 학내 Gateway 키를 프로그램에서 등록한다. 지원되는 Chat Completions 모델은 선택/직접 입력할 수 있고 특정 모델에 고정하지 않는다. PDF·이미지 계약서를 분석하려면 이미지 입력 지원이 필요하다. 본문 전체를 상시 보내지 않는다. 키는 DPAPI로 암호화해 PC에 저장한다. 텍스트/이미지 연결 확인은 실제 API 요청으로 사용량이 발생할 수 있다. 가격·모델 목록은 학교 운영자료로 확인해야 한다.

## 상담자료
상단 ‘챗봇 도움’ 또는 AI 연결 설정 안의 ‘챗봇 도움’ → 사업(선택), 문의 종류, 질문, 오류 → 상담자료 미리보기 → 확인/내용 삭제 후 복사 또는 TXT 다운로드.
기본은 버전·운영체제·Python 버전·모델명·키 등록 여부·화면·사용자 질문/오류다. 프로젝트를 골라도 파일 목록은 자동 포함하지 않는다. 별도 체크했을 때 현재 폴더 구조·파일 목록·계약 현황·최근 이력을 추가한다. 키 복호화·문서 본문 읽기·AI 호출·자동 전송·파일 이동을 하지 않는다. 현재 상태 요약에는 개수 제한과 생략 표시가 있을 수 있다. 과거 상세는 누적 ZIP을 이용한다.
초기 설치 실패로 앱이 열리지 않으면 이 기능도 사용할 수 없다. 오류 화면과 실행한 설치/업데이트 파일 이름으로 시작한다.

## 누적 이력 해석
시작 화면에서 사업 선택 → 누적 정리 이력 ZIP 다운로드. ZIP 안에는 ‘00 읽어주세요.txt’, ‘01 전체 이력 목록.txt’, ‘현재 상태.txt’, 날짜/회차별 ‘정리 이력.txt’와 ‘상세 기록.json’이 있다. 과거 회차는 덮어쓰지 않는다. 구버전은 저장됐던 정보만 포함한다.
`moved` 당시 이동 완료 / `held` 원래 위치 보류 / `pending` 이동 전 / `prepared` 준비 기록·완료 확인 필요 / `failed` 실패 / `already-in-place` 이미 제자리 / `restored` 되돌림 / `undo-blocked` 복원 보류.
같은 회차의 정리안, 실행 이벤트, 마침, 되돌리기를 시간 순으로 연결한다. 정리안과 실행 기록에 반복된 파일을 중복 집계하지 않는다. 기록 밖의 사용자 수동 변경은 알 수 없다. 새 기록 시각은 한국 시간이며 구버전은 당시 PC 시각일 수 있다.
